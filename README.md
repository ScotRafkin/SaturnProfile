# CASSPIAN

Saturn atmosphere reference model: the reduction of published radio occultation profiles to
registered refractivity, and the forward transfer of that refractivity to temperature and
pressure at a chosen latitude.

`docs/specs/SPEC_00_Architecture_and_Data_Files.md` is the architecture: the repository layout,
the package structure, the file kinds, and the provenance rules. It is the document every other
specification cites.

`docs/specs/STATE.md` is the current state of the build, one row per step.

This package is proprietary to Southwest Research Institute and is not to be distributed.
