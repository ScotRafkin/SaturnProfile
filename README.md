# SaturnProfile

CASSPIAN Occultation Reconstruction Toolkit: modular Python toolkit to reconstruct atmospheric profiles from radio occultation data, starting with Voyager 2 (Lindal et al. 1985).

## Quick Start

```bash
pip install -e .
python -m occultation_recon.build_table1_netcdf
python -m pytest tests/ -v
```

## Data

- `data/lindal1985_table1.csv`: Digitized Table I from Lindal et al. (1985)
- `data/lindal1985_voyager2.nc`: Standard netCDF output (generated by `build_table1_netcdf`)
